# Research ledger

## Integration evidence

The implementation now has 18 passing native Rust tests and a passing compiled-WASM integration script. Independent review reproduced and then verified a correction for imported allocator exhaustion. The corrected allocator preserves IDs across undo and redo while finding a free range after wraparound.

`ModelLibrary` generates six architectural types in three deterministic approved variants, composes facade and roof details, and reuses two licensed GLB components. `Terrain` instances repeated ground and vegetation. The browser contact sheet shows the eleven objects at both requested resolutions. Five normalized runtime GLBs pass geometry, texture, transform, bounds, and provenance validation.

The first 500-structure performance experiment confirmed 505 draw calls and 475,229 rendered triangles. Its software-renderer throughput was contended by parallel regression tests and a build. It is retained in `docs/benchmarks/software-renderer-before-contended.json` as a diagnostic, not a speed baseline. The final implementation groups shared structure geometry into instances. The isolated production run submits 25 draws. Final clean measurements and remaining acceptance work are recorded in `performance.md`.
