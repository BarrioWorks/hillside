# Research decisions for Barrio Builder

The implementation contract requires an editable 32 by 32 terraced board, deterministic saves, six building types, and local gameplay. Use a seeded constructive generator with placement validation. Full WFC adds authored adjacency rules and contradiction handling without a demonstrated gameplay need. This is an engineering decision, not a measured speed comparison.

Research was performed on 2026-10-20. Source code and licenses were downloaded from pinned GitHub commits. Copies are under `tools/research/sources/OWNER__REPO/`, with `repository.json` recording each commit. This research copies no upstream generation code into the game. The source excerpts remain subject to their accompanying licenses.

## Rendering adaptations

`OrbitControls` supports orthographic zoom and pan, pointer gestures, and bounded camera movement. Its damping requires `update()` during animation. Put camera ownership in the renderer and use `web/src/input.ts` to distinguish clicks from orbit drags. A pointer release after dragging must not place a house. Dispose controls when tearing down the view.

`GLTFLoader.load` resolves external buffers and textures relative to its resource path and reports failures through its error callback. The acquired models need `Textures/colormap.png`. Adapt in `web/src/render/models.ts` and `tools/asset-pipeline/`. Load local normalized assets once, cache their geometry, and provide an explicit loading failure state. The observed loader is now `web/src/render/assets.ts`. A local asset fetch is permissible. Gameplay rules must remain local Rust calls.

The instancing example compares one shared geometry/material `InstancedMesh`, merged geometry, and independent meshes. `InstancedMesh.setMatrixAt` writes instance transforms. Mark `instanceMatrix.needsUpdate` after edits, and recompute bounding volumes when needed for culling or raycasting. Maintain a placement-ID-to-instance-slot map if using instance picking. These APIs are accepted, but no performance superiority has been measured here. Use repeated terrain and foliage as initial candidates. Six buildings with different submeshes and materials cannot become one arbitrary instanced draw call.

The shadow example enables `renderer.shadowMap`, a casting light, receiving ground, and casting models. Adapt one bounded directional shadow camera for this small board. Shadow maps add rendering work. Choose map size and pixel ratio using the parent browser benchmark, not the upstream demo's appearance. Keep the 500-structure FPS measurement separate from core command latency and asset byte counts.

## Publications

[Müller et al. 2006, DOI 10.1145/1141911.1141931](https://doi.org/10.1145/1141911.1141931) was read through the [author-hosted full paper](https://peterwonka.net/Publications/pdfs/2006.SG.Mueller.ProceduralModelingOfBuildings.final.pdf). CGA shape builds massing before facade components. Section 2 distinguishes absolute from relative subdivision sizes. Section 3 uses context and occlusion to avoid conflicting elements. Section 8 acknowledges implausible results and unresolved real-time rendering work. Adapt mass, facade, then detail composition in `web/src/render/models.ts`. Keep grille thickness and parapet depth deliberate when resizing shells. Reject a grammar interpreter and any inference that the paper proves this game's FPS or cultural accuracy.

[Farrokhi Maleki and Zhao 2024, DOI 10.1609/aiide.v20i1.31877](https://ojs.aaai.org/index.php/AIIDE/article/view/31877), including the [primary PDF](https://ojs.aaai.org/index.php/AIIDE/article/download/31877/34044/35946), was read. It distinguishes game bits from game space, surveys search, learning, noise, and grammar methods, and discusses combinations. Its recent-paper sample covers selected conferences in 2019-2023, so it is not an exhaustive quality ranking. Section 3 describes reproducibility from a seed and algorithm. Apply that to terrain and building variation. Reject runtime LLM services, training, and search optimization because the contract requires offline rules and specifies no learned objective. The survey supplies context, not a benchmark or implementation recipe.

The mixed-initiative design is a project interpretation. The generator supplies a starter neighborhood and seed variation. The player chooses placements, rotations, removals, and undo. Preview explains constraints before committing. No optimizer silently changes the player's neighborhood. `Controller` delegates preview and command validation to Rust. Do not describe this as a user study or as a reproduced paper result.

## Medellín references and visual limits

[Alcaldía, Comuna 13 escalators](https://www.medellin.gov.co/es/sala-de-prensa/noticias/las-escaleras-electricas-de-la-comuna-13-en-medellin-una-transformacion-urbana-que-cambio-vidas/) supplies a primary account and photograph. The inspected photo shows stairs beside an escalator, railings, planting, retaining walls, and painted surfaces. Adapt stairs, planters, and readable hillside access. Comuna 13 is the San Javier comuna. It is not interchangeable with a single barrio or the whole city.

[Alcaldía, Manrique macromural](https://www.medellin.gov.co/es/sala-de-prensa/noticias/la-comuna-manrique-tendra-el-macromural-artistico-mas-grande-de-medellin/) describes planned facade, party-wall, and end-wall artwork. The inspected photo shows painted masonry, exposed brick, and a grille. Adapt restrained plaster colors, brick accents, and grilles. Do not copy the depicted mural or present all Medellín houses as painted murals.

[Metro de Medellín, Línea K anniversary](https://www.metrodemedellin.gov.co/al-dia/noticias/metrocable-l%C3%ADnea-k-15-a%C3%B1os-de-mejor-calidad-de-vida-para-la-zona-nororiental-de-medell%C3%ADn) identifies Santo Domingo and the transport connection. Its inspected photo shows dense low-rise hillside development behind the station, vegetation, and mountains. Adapt stepped density and a planted distant hillside. A cable transport simulation is outside this contract.

These three photos were downloaded and visually inspected. They are reference-only files under `tools/research/sources/`. No redistribution license was established for game use. Flat roofs, terraces, and tanks are requested art direction, not a claim that these photos establish their prevalence across every named neighborhood. The municipal [San Javier local development plan](https://www.medellin.gov.co/ndesarrollo/wp-content/uploads/archivos/PDLS/pdl_C13.pdf) was discovered but not read in full. Do not treat it as evidence for detailed facade geometry.

## Local implementation review and unresolved checks

The actual `terrain.rs` uses a seeded integer mixer, four X bands, and stepped Z terraces. `catalog.rs` defines eleven catalogue entries and rotates multi-cell footprints. `world.rs` has `preview`, directional stair edges, connectivity traversal, `starter`, and `benchmark`. `Controller.refreshPreview` delegates to the core. These are source observations, not passing tests. The renderer and pipeline are being authored concurrently. `models.ts`, `terrain.ts`, and `thumbnails.ts` existed at review time. `world.ts` now configures orthographic OrbitControls, damping updates, a 2048-square directional shadow map, and stable-ID mesh reconciliation. `terrain.ts` uses instanced soil, surface cells, mountains, and vegetation. `models.ts` currently composes six catalogue buildings from procedural geometry. `assets.ts` loads the Kenney `building-a.glb` as a separate landmark and has a loading/error/ready state. This means the licensed geometry is currently planned for the landmark rather than the six placeable buildings. The contract asks for imported geometry in the renderer, but broader use in editable architecture needs an explicit integration decision. At this inspection, `tools/asset-pipeline/` and `web/public/models/` were empty. Final asset consumption, failure handling, six silhouettes, and shadow behavior still require integration verification. `package.json` requests Three.js 0.180, while the pinned upstream inspection used the dev branch. Verify API behavior against the installed package before adapting dev-only behavior.

The DOI redirect for Müller failed in the web reader. The author PDF succeeded through terminal download and Ghostscript text extraction. The EDU public-architecture book exceeded the web reader's file-size limit and was not read. One terminal request to AAAI closed without a response. Its primary PDF was successfully read through the web tool. Quaternius's Google Drive folder and itch.io's pack download were not opened because the licensed Kenney selection was already available. No source was represented as read solely because a link was found.
